---
title: Updates to AI Gateway invoices and model names
description: AI Gateway invoices now show the total monthly cost per model, while invoices and logs use consistent model names.
products:
  - ai-gateway
date: 2026-09-01
---

AI Gateway invoices now summarize usage as a single monthly cost for each model, making it easier to understand and reconcile your AI spend. Invoices no longer break out input and output token quantities and unit prices into separate line items.

AI Gateway has also standardized model names across invoices and logs. Model variants that previously appeared with provider-specific version suffixes now use a consistent `provider/model` identifier. For example, a model previously shown as `gpt.5.4-nano-20260103` may now appear as `openai/gpt-5.4`.

For more information, refer to the [Unified Billing documentation](/ai-gateway/features/unified-billing/) and [AI Gateway logging documentation](/ai-gateway/observability/logging/).
